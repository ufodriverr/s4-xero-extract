# Legal notice

## Project and game content

s4-xero-extract is a free, unofficial fan-made tool. It reads the resource
archives of an **S4 League** client that the user has installed, namely the
client distributed by the **Xero** private server, and writes the decoded
resources to a folder the user chooses, for use with a compatible engine
reimplementation on the user's own computer. The maintainer develops and
distributes it as a personal, noncommercial project for compatibility, learning
and preservation.

The project distributes its own source code and documentation only. Game
archives, executables, models, textures, animations, sounds, music, fonts,
scripts, data tables and extracted output are not included. Extracted content
and other game-derived output produced locally are not licensed by this project
and are excluded from its distributions.

## Use only your own installed client

Use the tool only on a client you have installed yourself. The extracted files
are for personal, local use. Do not share, upload or redistribute them. Do not
upload game files or extracted content to the repository, issues, pull
requests, releases or CI artifacts. Report bugs in your own words, without game
content or private filesystem paths.
